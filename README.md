#  Student Registration Portal

A modern, production-ready full-stack management interface built to handle student registry profiles and housing queues. This application is engineered using **Next.js (App Router)**, **TypeScript**, and modular **CSS Modules** to ensure seamless performance, type safety, and an intuitive user experience.

---

##  Key Features

* **Next.js App Router Architecture:** Utilizes modern file-based routing and persistent structural layouts.
* **Static Type Safety:** Fully typed with TypeScript to enforce robust data shapes across form submissions and state handlers.
* **Persistent Dashboard Layout:** Layout includes a fixed top **Navbar**, a structural **Sidebar** navigation tree, and a clean **Footer**.
* **Interactive Registry Queue:** A responsive client-side student intake form utilizing synthetic React event handling (`React.ChangeEvent` and `React.FormEvent`).
* **Modular Styling:** Zero global style leakage using localized CSS Modules (`*.module.css`).
